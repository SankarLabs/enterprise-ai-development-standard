# Session handoffs

Create a dated handoff when work needs to continue in another coding-agent session.

Include:
- Project stage and approved scope.
- Current branch and worktree state.
- Documents and files changed.
- Decisions made and their ADRs.
- Tests/checks run and actual results.
- Open questions and blockers.
- Exact next approved action.
- Actions that remain prohibited or unapproved.
