# Code standards

## General
- Prefer simple, maintainable solutions over unnecessary abstraction.
- Follow established repository patterns unless a reviewed decision changes them.
- Keep functions and modules cohesive.
- Use clear names and types; avoid untyped escape hatches.
- Comments explain why, not what obvious code already says.
- Never hard-code secrets.
