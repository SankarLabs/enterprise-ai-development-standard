# EADS methodology reference

The EADS lifecycle is Discover → Define → Architect → Govern → Plan → Approve → Implement → Verify & Operate.

Read the repository's `methodology/OVERVIEW.md`, `LIFECYCLE.md`, `ARTIFACT_CATALOG.md`, `APPROVAL_GATES.md`, `CHANGE_LIFECYCLE.md` and `AGENT_GOVERNANCE.md` for the full standard.

Three tiers:
- Tier 1: lightweight, low-risk utility.
- Tier 2: standard enterprise application.
- Tier 3: critical, regulated, sensitive-data, high-scale or multi-system platform.

The agent recommends a tier; a human project owner confirms it.
