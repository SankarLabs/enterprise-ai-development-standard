# Approval gate reference

G0: project intake.  
G1: requirements baseline.  
G2: architecture baseline.  
G3: delivery plan.  
G4: implementation authorization.  
G5: release authorization.

Implementation is blocked until G0–G4 have valid human approvals. Release requires G5. The agent must never approve a gate. See `methodology/APPROVAL_GATES.md` for required evidence and enforcement limitations.
