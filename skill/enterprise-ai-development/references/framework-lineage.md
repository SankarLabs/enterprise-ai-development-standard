# Framework lineage

EADS is an independent synthesis, not an official derivative or endorsed extension.

- GitHub Spec Kit: project principles, spec/plan/tasks workflow, clarification and convergence checks.
- OpenSpec: current specs separated from proposed changes; delta specs and archive.
- BMAD Method: adaptive depth and role-oriented review perspectives.
- AGENTS.md: shared repository instructions.
- Agent Skills: portable `SKILL.md` package with references/scripts/assets.
- arc42: architecture documentation completeness.
- C4: system context/container/component architecture views.

See the repository's `methodology/FRAMEWORK_RESEARCH.md` for source links, adopted ideas and limitations.
